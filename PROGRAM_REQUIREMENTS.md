# Business Simulation Suite Requirements

This repository implements `pr1.txt` as a SWI-Prolog suite with:

- deterministic simulation state and identifier generation;
- physical/virtual venue separation;
- consent-aware immersive narrative effects;
- ticketing, payments, and auditable ledger records;
- compliance and safety checks with blocking findings;
- scenario persistence and replay;
- command parsing and interactive REPL;
- documentation and CI-backed PlUnit validation.

The canonical specification source is `pr1.txt`.
