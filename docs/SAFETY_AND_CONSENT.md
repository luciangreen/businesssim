# Safety and Consent

The suite enforces blocked operations with exceptions for:

- actual memory manipulation;
- real teleportation claims;
- false venue claims;
- fake real customer reviews;
- hidden exits/restrictions;
- unlicensed real-person impersonation;
- payment for knowingly nonexistent events;
- presenting simulated attendees as real attendees.

Consent records are explicit terms with disclosures and versioning.
