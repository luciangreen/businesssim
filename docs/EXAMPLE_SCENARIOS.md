# Example Scenarios

## The Infinite Parlour

Demonstration flow:

1. create simulation
2. create business
3. create small physical venue
4. create large apparent virtual environment
5. schedule concert with disclosures and refund terms
6. run compliance check
7. accept payments / admissions
8. advance simulation
9. output event report

Run with:

```bash
swipl -q -s src/business_suite.pl -g run_demo -t halt
```
